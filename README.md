## Arquivos

- `index.html`: estrutura da página.
- `styles.css`: estilos visuais e layout.
- `script.js`: lógica de criação de blocos, salvamento local e abertura de links.

## Funcionalidades

- Criação de blocos de links com nome personalizado.
- Adição, edição e exclusão de links dentro de cada bloco.
- Botão "Abrir links" para abrir todos os links do bloco em novas abas.
- Cache local usando `localStorage`, preservando os dados apenas neste perfil de navegador.
- Separação clara entre HTML, CSS e JavaScript.
